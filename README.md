# Hiruy Recipe Platform 🍲

A recipe website built with React and Tailwind CSS. This project helps users explore recipes, view ingredients and instructions, and add their own recipes.

## ✨ Features

- View different recipes
- Search recipes by title
- Add new recipes
- View recipe details, ingredients, and instructions
- Edit and delete user-added recipes
- Add recipes to favorites
- Hide and show the recipe list
- Save recipes and favorites using localStorage
- Responsive design with Tailwind CSS

## 🛠️ Technologies Used

- React
- JavaScript
- Tailwind CSS
- React Router
- Vite
- HTML
- localStorage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/eluyosef16-gif/React-with-tailwind-incremental-recipe-.git
```

### 2. Open the project folder

```bash
cd React-with-tailwind-incremental-recipe-
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
